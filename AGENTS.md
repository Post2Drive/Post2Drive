# Agent design-review instructions

For Post2Drive UI/UX audits and design improvement work, use the Apple Design Skill at `.agents/skills/apple-design/SKILL.md`.

Before each review:
- Read `SKILL.md` and load the required HIG references: `accessibility.md`, `layout.md`, `typography.md`, `color.md`, and the relevant platform guide.
- Because Post2Drive uses Next.js/React, also read `references/cross-platform.md`; apply Apple guidance as transferable design principles, not as a claim that the web app is a native Apple app.
- Load only the additional component references relevant to the screen or workflow under review.
- Cite the exact reference filename and heading for guideline-based findings; label general design judgment as judgment.
- Report concrete fixes, priorities, trade-offs, and what cannot be verified from source alone.

Use this skill as review guidance. Do not merge branches, deploy, change production, or run destructive QA without explicit authorization. The canonical application source remains `Post2Drive/post2drive-app`; this repository remains the project/profile repository.
